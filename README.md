# Hiša priložnosti

Koncept spletne strani za HIŠA PRILOŽNOSTI, zavod za razvoj, podporo in povezovanje, Tlake.

Odprite `index.html` v brskalniku.

## Vsebina

- `index.html`: celotna stran (HTML, CSS in JavaScript)
- `slike/`: logotip in fotografije

## Opombe

- Besedila o zavodu so povzeta po ustanovitvenem aktu. Predstavitvi ustanoviteljic, e-pošta in telefon so v oglatih oklepajih in jih je treba dopolniti.
- Dogodki so primeri.
- Fotografija v glavi je narejena z AI. Ostale fotografije so ilustrativne (Picsum) in jih je treba zamenjati.
- Animacije uporabljajo GSAP 3.12.5 s ScrollTrigger (cdnjs).
